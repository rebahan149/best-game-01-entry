**EMBERLINE** — a wildfire defense game in vanilla JavaScript and canvas, no library, no build step, no network. Lightning strikes the dry east of the valley and the wind walks the fire toward a village in the west. Across seven nights of rising wind and dryness you hold the line with three tools: **cut** firebreaks to bare earth, **soak** the front (or the roofs) with helicopter water drops, and light **backfires** — controlled burns with a blue root that eat the fuel gently before the wildfire arrives. A cellular fire simulation drives it all: wind-bent spread, ember spotting that can jump a narrow break, wet ground that refuses to catch, and a firestorm on night seven whose wind veers mid-night. Between nights, a workshop offers one of three upgrades (bigger tank, wide bucket, ember shutters, a second crew…). Score is buildings saved, valley saved, and tempo. All art is painted in code and all sound — wind, crackle, water, the alarm when a house catches — is synthesised with WebAudio. Title, briefing, report and ending screens; pause, 2x speed, restart and mute; every night is generated from a seed, so the valley is the same for everyone.

## Run it

```sh
node serve.ts          # serves game/ on http://localhost:8080 — then just play
node main.ts           # hands the game in: copies game/ + screenshots/ to /output with dossier.json
```
